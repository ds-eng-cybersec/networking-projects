# subnet-calc

Quick subnet reference tool. Enter a network address and get the key details back — network, broadcast, mask, host
range, usable addresses. Handles IPv4 and IPv6.

## Usage

```bash
python cli.py
```

## Features

- Input validation
- IPv4 and IPv6 support
- Handles edge cases (/32, /31, /128, /127)

## Requirements

Python 3.x — no external dependencies.
